`days` lists the day numbers on which a member practiced, in no particular order and possibly
with duplicates. A streak is a run of consecutive day numbers (`d, d+1, d+2, ...`).

Return the length of the member's longest streak, or `0` if they never practiced.

**Constraints**

- `0 <= days.length <= 10^5`
- `-10^9 <= days[i] <= 10^9`

Can you do it in linear time?
